# StyleGAN-NADA: инверсия и стилизация изображений

### О проекте

Проект представляет собой полный pipeline для генерации, инверсии и стилизации изображений с использованием StyleGAN2 и StyleGAN-NADA.

Проект является реализацией и расширением метода StyleGAN-NADA, описанного в статье:

https://arxiv.org/abs/2108.00946

Основная идея заключается в адаптации предварительно обученного генератора StyleGAN2 к новому визуальному домену с использованием текстовых описаний и CLIP без необходимости в изображениях целевого домена.

### Возможности

- **Стилизация по текстовому описанию:** адаптация генератора StyleGAN2 к новому домену с помощью исходного и целевого текстовых описаний.
- **Directional CLIP Loss:** выравнивание направления изменения изображений в пространстве CLIP с направлением между исходным и целевым текстовыми описаниями.
- **L2-регуляризация:** сохранение исходного содержания изображений во время стилизации.
- **Адаптивная заморозка слоев:** автоматический выбор наиболее важных слоев генератора для конкретного преобразования.
- **Инверсия изображений:** преобразование реальных изображений в латентное пространство StyleGAN2 перед стилизацией.
- **Работа с несколькими генераторами:** поддержка различных чекпоинтов StyleGAN2 для обучения и инференса.

### Процесс обучения

В процессе обучения используются две копии генератора StyleGAN2:

- **Замороженный генератор** — сохраняет исходный домен и используется как эталон.
- **Обучаемый генератор** — изначально идентичен замороженному и постепенно адаптируется к целевому домену.

Для одного и того же латентного вектора оба генератора создают изображения. Затем CLIP преобразует изображения и текстовые описания в общее пространство признаков.

Основная идея loss-функции:

- разница между признаками стилизованного и исходного изображений определяет **направление изменения изображения**;
- разница между признаками целевого и исходного текста определяет **текстовое направление**;
- модель обучается делать эти два направления максимально похожими.

Дополнительная L2-регуляризация помогает сохранить структуру исходного изображения.

### Адаптивная заморозка слоев

В проекте реализован метод адаптивного выбора обучаемых слоев StyleGAN2.

Сначала оптимизируется представление W+ с использованием CLIP loss. После этого анализируется изменение отдельных компонентов W+, чтобы определить, какие модули генератора оказывают наибольшее влияние на целевое преобразование.

После выбора наиболее важных модулей обучаемыми делаются только соответствующие слои генератора.

### Инверсия и стилизация

Реальные изображения могут быть преобразованы в латентное пространство StyleGAN2 и затем стилизованы обученным генератором.

Pipeline инференса:

1. Подготовка входного изображения.
2. Выравнивание лица.
3. Инверсия изображения в латентное пространство.
4. Генерация исходного изображения.
5. Стилизация с помощью обученного генератора.
6. Сравнение исходного и стилизованного изображений.
